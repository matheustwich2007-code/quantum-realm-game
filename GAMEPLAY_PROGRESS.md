# Quantum Realm: Nexus

## Progresso da versão jogável
Este projeto foi evoluído para incluir:
- fluxo de menu principal e início de partida
- sistema de rounds por onda
- HUD com vida, munição, XP, score e wave
- eventos de morte de inimigos para avanço da partida
- base de inimigo com dano ao jogador
- suporte inicial para controles mobile
- sistema de vida do jogador com game over

## Próximo alvo
A próxima etapa será a consolidação da versão mobile jogável completa, incluindo:
- touch input refinado
- mira em primeira pessoa
- weapon selection/weapon slots
- VFX de dano e disparo
- UI de pausa, vitória e derrota
- salvamento persistente de progresso
