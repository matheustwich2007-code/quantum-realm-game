# Quantum Realm: Nexus

Sistema base para um FPS mobile com mecânicas quânticas, IA básica e progressão.

## Visão geral
Este projeto serve como base para um jogo FPS mobile com:
- controles touch para mobile
- movimentação e câmera do jogador
- disparo e recarga
- inimigos com IA básica
- habilidades quânticas
- progressão por XP e nível

## Estrutura
- `Assets/Scripts/Core` — gerenciamento do jogo
- `Assets/Scripts/Player` — jogador e combate
- `Assets/Scripts/Enemy` — IA dos inimigos
- `Assets/Scripts/Systems` — habilidades e progressão

## Como usar
1. Abra o projeto no Unity 2022 LTS ou superior.
2. Crie uma cena nova.
3. Adicione o `GameManager` e o `PlayerController`.
4. Crie um prefab de inimigo com `EnemyAI`.
5. Ajuste parâmetros de câmera, velocidade e balanceamento.
